# harpy

Custom extensions, prompts, and themes for the [Pi coding agent](https://github.com/badlogic/pi-mono/tree/main/packages/coding-agent).

Harpy is a repo-local Pi package: clone it, run `./setup.sh`, and Pi picks up the extensions, theme, and prompt additions from your checkout.

I built this for myself. You're welcome to use it, and I'm happy to answer questions, but setup is opinionated and may be rocky.

## What's included

| Path | Adds |
|---|---|
| `extensions/agentkb.ts` | `kb_search`, `kb_read`, `kb_list`, `kb_chat_read`, `kb_wiki_path` |
| `extensions/rlm.ts` | `rlm_query` for programmatic KB investigations |
| `extensions/colgrep.ts` | `colgrep` semantic + regex code search |
| `extensions/git-dashboard.ts` | `git_dashboard` repo snapshot |
| `extensions/review-prep.ts` | `review_prep` commits + diffstat + diff |
| `extensions/list-dir.ts` | `list_dir` recursive tree view |
| `extensions/web.ts` | `web_fetch` for web pages, YouTube transcripts, and PDFs |
| `extensions/gemini.ts` | `gemini` for PDF/image/video analysis |
| `extensions/think.ts` | `think` planning step |
| `extensions/diff-view.ts` | richer rendering for `edit`/`write` diffs |
| `extensions/read-view.ts` | cleaner collapsed summaries for `read` results |
| `extensions/prevent-idle-sleep.ts` | macOS idle-sleep prevention via `caffeinate` |
| `prompts/APPEND_SYSTEM.md` | global prompt additions for AgentKB, colgrep, RLM, GitHub API, and Gemini guidance |
| `themes/ghostie.json` | Ghostty-friendly light theme |

## Who this is for

This repo is first a working personal setup. It is not polished like a general-purpose Pi starter kit.

If you want to borrow from it, the best move is usually to point an agent at this repo and ask it to pull the parts you want into your own setup.

If it saves you time, leave a star.

## Install

### Prerequisites

- Node.js 20+
- Pi installed locally
- Optional: AgentKB installed locally if you want the KB tools/skills to work end-to-end

If Pi is not installed yet:

```bash
npm install -g @mariozechner/pi-coding-agent
```

Then install Harpy:

```bash
git clone https://github.com/Isaac-Flath/harpy.git
cd harpy
./setup.sh
```

`setup.sh` does three things:

1. installs npm dependencies
2. symlinks `prompts/APPEND_SYSTEM.md` into `~/.pi/agent/APPEND_SYSTEM.md`
3. registers this repo's `extensions/` and `themes/` in `~/.pi/agent/settings.json`

If `~/.agentkb/skills/.claude/skills` exists, it also symlinks those skills into `~/.pi/agent/skills`.

Re-run `./setup.sh` after changing prompts, extensions, or themes.

## Setup gotchas

- `setup.sh` writes to `~/.pi/agent/settings.json` and symlinks `prompts/APPEND_SYSTEM.md` into `~/.pi/agent/`.
- The AgentKB tools are useful only if you already have local `agentkb` data and the `agentkb` CLI installed.
- `setup.sh` links AgentKB skills only when `~/.agentkb/skills/.claude/skills` exists.
- `rlm_query` is part of the normal extension set, but notebook reruns and deeper local experiments also rely on local model auth being configured in Pi.
- `gemini` needs Gemini credentials in your environment.

## Scripts

- `./setup.sh`: local install/update script for this repo
- `npm run spike -- "question"`: standalone RLM smoke test and debugging helper
- `scripts/rlm-server.ts`: internal helper for notebook reruns generated by RLM logs

## Gemini

The `gemini` tool uses the Gemini API directly from the Pi extension layer.

Requirements:

```bash
# Direct Gemini API
export GEMINI_API_KEY=...

# Optional Vertex AI fallback
export GOOGLE_GENAI_USE_VERTEXAI=true
export VERTEX_AI_API_KEY=...   # or GOOGLE_API_KEY=...
```

The tool tries the direct Gemini API path first and, if that errors, retries with Vertex AI when configured.
Use it for PDFs, images, and videos — not as a general long-context text or code-analysis tool.
