# Isaac-specific skills

- `content-publishing`: copy, CTAs, export naming, news storage/drafts, and webinar conventions.
- `content-style`: real-photo/source-evidence preferences and thumbnail styling.

Tools, workspace locations, timezone, buckets, and the public-delivery approval
rule live in `../APPEND_SYSTEM.md`. Project procedures stay in the website repo;
API usage comes from the configured tools and their current documentation.

No bundled API clients or OAuth helpers. Ordinal uses its configured MCP server.
YouTube thumbnail uploads require separate available tooling or YouTube Studio;
Harpy does not provide a thumbnail-upload command.
